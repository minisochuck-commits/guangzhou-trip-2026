# 广州行程 Guangzhou Visit · 2026-09-20 – 2026-10-07

MINISO Egypt 一行 5 人赴广州的行程分享页。手机优先，三语（中文 / English / العربية），
公开访问，无登录无密码。

- 站点原始 starter 文档（vinext / Sites 生命周期、D1、Wrangler 等）保留在
  [`docs/VINEXT_STARTER.md`](docs/VINEXT_STARTER.md)。
- 设计与取舍记录在 [`DESIGN_NOTES.md`](DESIGN_NOTES.md)。

## 页面结构

顶部：标题 + 日期区间 → 语言切换（中文 / English / العربية）→ 查看对象切换
（全部 / 5 个单人）→ 全局提示条。下面是三个 tab：

| Tab | 内容 |
| --- | --- |
| 日程 | 人员名单（可展开）、日期导航、按天的事件卡；9/26 附城市体验建议 |
| 吃住行 | 住宿 / 餐饮 / 交通分区，末尾是可展开的「待确认清单」 |
| 来华指南 | 网络、支付、地址（可复制中文地址）、证件、餐饮、落地、时间；底部官方来源链接 |

页面底部还有一个可展开的「参考：总部通知」，用于放总部通知截图与要点。

**查看对象切换是阅读筛选，不是权限隔离。** 页面本身是公开的，所有语言、所有人的行程
在同一份公开数据里；切换只决定当前显示哪些条目。

- 「全部」视图把同一场安排合并成一张卡，并在卡片底部列出参与者。
- 单人视图只保留该人参与的事件，以及与他相关的住宿 / 交通条目。

## 状态口径（不要改写）

| 标记 | 含义 |
| --- | --- |
| 已确定 Confirmed | 已经定下来的事实（航班、已确认的参会日） |
| 建议安排 Suggested | 只是建议，**没有预订、没有安排** |
| 待确认 To confirm | 还没定，需要有人去定 |

页面任何地方都不得把「建议安排」写成已预订 / 已安排。

## 未定事项（页面上就叫「待确认清单」）

数据里 `OPEN_ITEMS` 是这份清单的正本，页面 `吃住行 → 待确认清单` 直接渲染它。当前包括：

- 酒店：名称、地址、房型、预算、是否含早、9/27 是否延迟退房 / 日间房
- 用车：接机车辆与车牌、司机、每日接送、9/27 从酒店出发的时间
- 联系人：机场接机联系人；**9/27 晚间送机的陪同接待人（RAHMA 计划 17:25 起飞，无法陪同 REHAM 23:20 的夜班机）**；带教陈俊杰可对外分享的联系方式
- 门店：黄埔云汇天地店准确街道与入口；每日开课 / 下课时间
- 接待组：9/22–26 商务日程、拜访对象、需要哪些预约
- QIUTING：是否参加 9/24 上午场、离穗日期、返乡城市、返穗交通
- 9/23：是否报名总部第一批门店巡店
- 饮食：清真 / 过敏 / 忌口；会务餐是否供给
- 行李：中转是否直挂（以值机柜台为准）

## 怎么更新

所有文案和行程都集中在两个文件，改数据不需要动组件：

| 文件 | 放什么 |
| --- | --- |
| `lib/trip-data.ts` | 人员、机场、**逐条事件**、城市体验建议、吃住行分区、待确认清单、来华指南、可复制地址、官方链接、底部参考 |
| `lib/trip-i18n.ts` | 界面文案（tab 名、状态名、按钮字）与日期格式化 |

组件：`components/trip/`（`trip-view.tsx` 壳 + 三个 tab + `ui.tsx` 公共件），
页面入口 `app/page.tsx`，配色在 `app/globals.css`。

### 加 / 改一条行程

在 `lib/trip-data.ts` 的 `EVENTS` 里增删对象。要点：

- 三语 `title` 必填；`summary` / `details` / `pending` 按需要给。
- `people` 决定这条在谁的视图里出现；写全所有参与者，全员视图靠它合并显示。
- `status` 只能是 `confirmed` / `suggested` / `pending`，对应上表三种标记。
- `date` 用 `YYYY-MM-DD`；跨日阶段用 `endDate`，**区间里的每一天都会出现在日期导航上**，
  并在这些天里重复显示同一张卡（接待组 9/22–26、QIUTING 9/25–10/5 都要能逐日点开）。
- `time` + `tz` 一起给才算「有确切时刻」。有时刻的事件按**真实时间轴**排序
  （北京 UTC+8、开罗 UTC+3），所以 9/21 的开罗 00:20 会排在成都 08:00 前面，
  跨时区和午夜不会颠倒。
- **没有时刻的事件不要编时间**，它们会自动归到当天的「时间待定的安排」一段里。
- 航班用 `flight` 字段；出发地是 `CAI` 时自动标开罗时间，否则标北京时间。

### 换语言文案

`lib/trip-i18n.ts` 的 `UI`。所有条目都是 `{ zh, en, ar }`，缺一个 TypeScript 会报错。

### 底部参考图

当前挂的是 `public/reference/hq-notice.png`（总部面向全体的总通知原件），
在 `lib/trip-data.ts` 的 `REFERENCE_IMAGES` 里登记，图下三语说明写明
