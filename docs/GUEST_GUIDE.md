## 本轮要求与实现（2026-09-11 用户确认，页面质感与好用）

用户这次要的是「手机上更耐看、指南更好用」，明确**不要**把整页重构成卡片式旅游落地页。
行程事实一律不动：航班、免费行李额、机场、日期、分房、活动与接送照旧；默认 Reham、
URL 的人员与语言参数、三列（日期 / 活动与交通 / 食宿）、日期跳转、合并规则都保留。

以下两条被**替代**，不要再当成现行做法：

- **页头常驻六个人的横滑按钮** → 换成一个紧凑的人员下拉（`NativeSelect`）。
  默认显示 Reham 的名字，点开才列出其他人和「全部」。页头同时去掉了木棉背景花纹和投影，
  日期区间与当前的人各写一次，不再重复。语言切换仍在页头，保持 44px 可点高度。
- **指南是十几张长相一样的白卡** → 改成两组：「出行随手查」（出发前准备、机场中文地址、
  中文短句、礼拜与清真餐、半日路线、免费行李额）和「认识广州」（广州与你们、这座城有多大、
  科技就在身边、琶洲、食在广州、商圈、文化差异、官方来源）。一组共用一张卡，
  组内每节之间只有一条细线。仍然复用 `Accordion` / `CopyChinese` / `SourceLink`，
  仍然按需展开（`defaultValue={[]}`），没有新增大图欢迎区。

其余落实：

- **酒店那块只写一次**：酒店名、一条中文地址（可复制、举给司机看）、前台电话、
  Reham 的接送说明。标签不再把酒店名重复一遍。
- **出发前准备加勾选清单**：支付、打车、地图、上网、随身物品五项由现有 PREP 生成，
  标题当动作名，完整原说明收在同一行的「怎么做」里按需展开 —— 勾选**不会**收走说明，
  完成后仍可查看。天气不设勾选（它是提醒，不是能做完的事）。
  计数是一行小字（已完成 3 / 5），不做进度仪表盘。
  状态只存在本机 `localStorage`，键 `gz-trip-prep-done.v1`，**按人分桶**；
  「全部」视图另占一个桶，不会把某个人的准备标成完成。服务端渲染与存储不可用时
  一律当作没勾过，页面照常能用。逻辑在 `lib/prep-checklist.ts`，断言见
  `lib/prep-checklist.test.ts`。
- **路线收起来就能选**：折叠状态显示 96×72 小图 + 名字 + 已有时长 + 「适合什么」一句
  （收起时截两行，展开显示完整，所以展开后不再重复这句）。展开仍是既有的顺序、交通、
  中文地址、票务与来源，没有新增票价或营业时间。
- **排版**：日期列的日号放大、月与周几压小，表格分隔线换成更淡的一档，行距放宽；
  窄表最小字号抬到 14px（原来有 13px 的按钮与眉批），正文维持 16px；
  点击目标保持 ≥44px。页面不再用 `overflow-x` 把横向溢出裁掉。
- **商圈文案去掉无依据判断**：万菱汇的「有意错开」、时尚天河的「价格带最低」
  「没人用的空间」和客群标签都已删除，改成站在街上看得见的描述；
  天河路路线里「做商场的人来广州……」改成对客自然的说法。三语同步。
  `scripts/check-guest-guide.mjs` 已把这几句和 `ROUTES` 一起纳入禁用词检查。

## 当前依据（2026-09-11 用户确认）

核心读者为 Citystars 品类招商负责人 Reham。此行的主线是参加 MINISO 会议、了解货盘与旗舰店型；自由时间的商圈与城市探索由客人选择。页面要体面、实用、有趣，不向客人暴露内部商业目的，不指导其写报告，也不把逛商圈与给予 MINISO 商业政策建立因果关系。MINISO 的规模与实力由会议现场介绍，网页不另添宣传章节。

## 数据边界

- 支付、打车、地图与上网指引必须在 Reham 视图可见；不能因内部员工安排而隐藏公共说明。
- Chuck 借给 Mohamed 的中国 SIM 与给 Ahmed/Mohamed 的备用金仅归该两人。Reham 的网络方案不假定由公司提供。
- 日程事实留在原有数据与派生函数中。本轮不更改航班、免费行李额、日期或分房安排。
- 科技介绍提供体验入口和确认方式；不能把未核实的酒店机器人服务、无人商店或飞行体验写成已经安排。
- 商圈路线是游览顺序示意，明确不是地理地图。两商圈分开安排，提供中文目的地；交通时间使用出发当天地图，不能靠示意图估算。
- 车程一律不许给「即到 / 很近 / 短车程」这类承诺：没查过路况，一律写「出发前在地图里查当天车程」。
- 广州塔 09:30–22:30 是官网公布的总体营业时间，不能当作每个高空项目的结束时间；票价分层分项目，未核实不写具体数字。
- 珠江夜游不能说所有班次都途经广州塔：码头、船、路线各不相同，页面给的是订票时该核对什么。
- 页面上的照片必须是能认出地点的实景，且**不裁剪、不抹水印**；带水印或认不出地点的图直接不用，不为凑图硬上。
- 不加未实测的功能按钮（例如地图 URI 跳转）：文档查到不等于在真机上能打开。
- 已撤销：埃及/广州经济强弱比较、全球仅六座美食之都、擎朗为广东公司、完全没有业态竞争、将历史传说与准确年代混写。
